Introduction

ShiftGrid manages assignments across multiple labs and teams. It provides flexible lab configuration, POC tracking, and drag-and-drop schedule management.

Recommended Workflow:
  1. Configure Labs & Shifts
  2. Build Roster & Import Availability
  3. Create Teams & Define Demands
  4. Generate Backlog & Auto-Schedule

Labs Configuration

Configure labs with operating hours, shift lengths, and capabilities. Capabilities (e.g., "High Security") ensure shifts are only placed in qualified labs.

Roster & Availability

Manage all team members in one place. ShiftGrid supports Calendar Matrix imports to sync PTO and unavailability dates directly from spreadsheets.

Shift Demands

Demands define how many shifts each team needs. Set priorities and required capabilities to guide the scheduling engine.

Auto-Scheduling Engine

Our algorithm respects hard constraints: lab hours, POC availability, and the "Late-to-Early" rest rule.
